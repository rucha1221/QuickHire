# QuickHire – Online Job Portal

QuickHire is a full-stack job portal web application developed using HTML, CSS, JavaScript, PHP, and MySQL.  
The platform helps job seekers find opportunities and allows recruiters to manage job postings and applications efficiently.

## Modules

### Job Seeker
- Create profile
- Browse available jobs
- Apply for jobs
- Upload resume
- View applied jobs
- Get job recommendations

### Recruiter
- Create company profile
- Post new jobs
- Manage posted jobs
- View applications received
- Update application status

### Admin
- View users
- View job listings
- View applications

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## Project Highlights

- Authentication and Authorization
- Resume upload functionality
- Job recommendation feature
- Responsive user interface
- Separate dashboards for users, recruiters, and admin
- Password reset via email
